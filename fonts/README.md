# fonts/

Drop your test fonts here. The test scripts in `../test/` currently reference a
specific font path (`Antique-Legacy-Medium/Antique-Legacy-Medium.{ttf,otf,woff,woff2}`)
which is not included in this repo. Adjust the paths in the test files to point
at whatever fonts you place in this folder.

Files in this folder are gitignored (except this README).
